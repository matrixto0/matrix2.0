# MATRIX2.0 Explorer

The **MATRIX2.0 Explorer** turns mathematical and computational state concepts into simple, interactive, and enjoyable learning experiences.

## Core Philosophy

$$\text{COMPLEX MATH} \longrightarrow \text{SIMPLE CONTROLS} \longrightarrow \text{VISUAL RESULT} \longrightarrow \text{EXPERIMENT} \longrightarrow \text{LEARNING} \longrightarrow \text{CURIOSITY}$$

Learning progression follows a 5-level journey:
1. **LEVEL 1 — DISCOVER**: Simple everyday explanations.
2. **LEVEL 2 — PLAY**: Adjust parameters and observe outputs.
3. **LEVEL 3 — UNDERSTAND**: Discover underlying mathematical formulas.
4. **LEVEL 4 — EXPERIMENT**: Design custom parameter sweeps.
5. **LEVEL 5 — RESEARCH**: Export reproducible datasets.

## Modes

### Curious Mode
Encourages users to make predictions before running an experiment:
- *"What if I double the frequency?"*
- *"Why does this jitter pattern appear?"*
- *"Can I predict the wave peak before stepping?"*

### Research Mode
Designed for structured experiment execution:
- Parameter sweeps across frequency ranges.
- Seed-based deterministic runs.
- JSON/CSV dataset export.

## Product Strategy & Business Value

- **FREE (Core Open Source)**: Core state model, wave equations, particle fields, local scanner, educational concepts, basic CLI explorer.
- **MATRIX2.0 STUDIO**: Real-time visualizers, interactive lab dashboard, experiment builder.
- **MATRIX2.0 API**: Programmatic API for remote simulation execution and data analysis.
- **EDUCATION**: Interactive laboratory exercises, classroom tools, and guided learning courses.
- **RESEARCH**: Enterprise experiment management, simulation datasets, and technical consulting.
