# MATRIX2.0 Simulation Arcade

The **MATRIX2.0 Simulation Arcade** is an educational simulation suite where mathematical state concepts become interactive experiments.

## Universal Universal Game Loop

$$\text{INTRO} \rightarrow \text{LEARN} \rightarrow \text{PREDICT} \rightarrow \text{PLAY} \rightarrow \text{RUN} \rightarrow \text{OBSERVE} \rightarrow \text{COMPARE} \rightarrow \text{EXPLAIN} \rightarrow \text{TRY AGAIN}$$

---

## Game Directory

1. **Wave Runner (`wave_runner`)**: Adjust frequency, intensity, and phase to predict wave peak displacement.
2. **Phase Shift (`phase_shift`)**: Compare two wave systems under phase displacement shifts.
3. **Chaos Race (`chaos_race`)**: Predict trajectory divergence from minute Master Stroke parameter perturbations.
4. **Particle Dance (`particle_dance`)**: Observe multi-particle field evolution under frequency and chaos settings.
5. **Resonance Lab (`resonance_lab`)**: Align frequencies between two oscillating systems and measure correlation.
6. **Pattern Hunter (`pattern_hunter`)**: Discover periodic sequences and trends in dynamic wave step output.
7. **State Transformer (`state_transformer`)**: Transform text losslessly through text -> numbers -> state -> decode pipeline.

---

## Difficulty Levels

- **LEVEL 1 — Curious**: Basic parameter controls and simple everyday explanations.
- **LEVEL 2 — Explorer**: Multi-parameter adjustments and wave comparison metrics.
- **LEVEL 3 — Scientist**: Formal mathematical equations, superposition, and resonance correlation.
- **LEVEL 4 — Researcher**: Raw time-series trajectories, JSON/CSV dataset export, and seed determinism.

*Note: Difficulty levels represent educational learning modes.*
