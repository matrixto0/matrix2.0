# MATRIX2.0 Scientific Claims & Evidence Guidelines

This document establishes the scientific integrity protocol for experimental validation and claims in MATRIX2.0.

---

## 1. Epistemological Protocol

1. **Falsifiable Hypotheses**: Every experiment must declare a falsifiable statement prior to execution.
2. **Deterministic Seeds**: Random seed parameters must be fixed to allow 100% independent replication.
3. **Fair Baselines**: Model metrics must be compared against standard linear/constant baselines.
4. **Generated Data**: All benchmarks must be computed live rather than hardcoded or fabricated.

---

## 2. Model Capabilities vs Physical Causation

| Claim Category | Scientific Boundary |
| :--- | :--- |
| **Computational Output** | Reflects mathematical properties of the simulation model. |
| **Physical Causation** | Cannot be established solely through numerical simulation. |
| **Correlation** | Measures association between model parameters; does not prove real-world cause. |

---

## 3. Disclaimers

Every export, dashboard visualization, and analytical report in MATRIX2.0 includes:
`"Comparison describes differences between model outputs; it does not establish physical causation."`
