# MATRIX2.0 Experiments

This directory contains reproducible, deterministic experiments evaluating MATRIX2.0 state transformations, wave dynamics, and particle fields.

## List of Experiments

- `experiment_001.py`: **MOTHER symbolic transformation experiment**. Encodes text input "MOTHER" into a `MatrixState`, steps its wave dynamics over time, initializes a seed-controlled `ParticleField`, and outputs structured numerical observations.

## Running Experiments

```bash
python3 experiments/experiment_001.py
```
