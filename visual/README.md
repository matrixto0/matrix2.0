## Performance & Architecture

Visual datasets are formatted as lightweight JSON arrays without external GUI dependencies:
- **`wave_data.py`**: Time series plot points `[{"t": float, "value": float}, ...]`.
- **`particle_data.py`**: Node projections exposing `id`, `value`, `frequency`, `intensity`, `phase`, `x`, `y`.
- **`trajectory_data.py`**: State parameter evolution across time steps.
- **`comparison_data.py`**: Baseline vs perturbed trajectory differences.
